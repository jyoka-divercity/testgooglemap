# unimap（ユニマップ）
### 🌊 ♨️ 大分県別府市の留学生・旅行者向け「決済＆食の制限」グルメ案内Webアプリ

立命館アジア太平洋大学（APU）や別府大学の留学生、観光客が直面する **「入店したのに現金しか使えない（Cash Only問題）」** や **「ヴィーガン・ハラール・ベジタリアン対応の店が見つからない」** という課題を解決するために開発されたWebアプリです。誰もが安心して使えるユニバーサル（Universal＝uni）かつ大学生活（University＝uni）に寄り添う30店舗を網羅しています。

---

## 🌟 主な機能・特徴

1. **決済方法の事前確認（Cash Only警告＆各種キャッシュレス対応）**
   - 券売機や現金専用の店には **「⚠️ 現金のみ / Cash Only」** の目立つ警告バッジを表示。
   - クレジットカード、PayPay、交通系IC（Nimoca/Suica）対応店には **「💳 キャッシュレス可 / Cashless OK」** と対応ブランドを表示。

2. **食の配慮・制限フィルター（Dietary Options）**
   - **Vegan（ヴィーガン 🌿）**: 100%植物性・動物性不使用
   - **Vegetarian（ベジタリアン 🥗）**: 肉・魚不使用
   - **Halal-friendly（ハラール対応・ポークフリー 🍖）**: ハラール認証肉使用、豚肉・アルコール非使用

3. **ワンタップ4言語切り替え（EN / JP / KO / ZH）**
   - 画面右上の言語ボタン（**EN / JP / KO / ZH**）で、UI・カテゴリー・豆知識・各店舗の詳細情報（店名・料理ジャンル・おすすめメニュー・食の配慮方針・営業時間等）が即座に切り替わります。
   - 英語、日本語、韓国語（한국어）、中国語（中文）に完全対応。韓国語や中国語でのキーワード検索も可能です。

4. **エリア・キャンパス通学路絞り込み**
   - 別府駅周辺（Beppu Station）
   - 亀川・APU通学路（Kamegawa / APU Bus Route）
   - 鉄輪温泉街（Kannawa Onsen）
   - 餅ヶ浜・石垣（Mochigahama / Ishigaki）

5. **店舗詳細モーダル（ポップアップ）**
   - 詳しい決済ブランド一覧（Visa, PayPay, Nimoca, 現金など）
   - 食の配慮方針・アレルゲン注意事項
   - 留学生・学生向けサービス（🎓 学割、📖 英語メニュー、🗣️ 英語対応スタッフ、📶 Free Wi-Fi、🥡 テイクアウト）
   - 営業時間・定休日・Googleマップ外部リンク
   - お気に入り保存（❤️）＆リンク共有機能

6. **店舗追加・編集が可能な管理画面（Admin Console / ⚙️）**
   - ユーザーが自分でお店を自由に追加・編集・削除できる専用管理画面（`admin.html`）。
   - **リアルタイム表示プレビュー**: 入力内容に合わせて本番カードが動的にプレビュー表示。
   - **写真プリセットギャラリー**: カフェ、カレー、地獄蒸し、ラーメン、和食など12種類の高画質写真をワンクリック選択可能。
   - **決済＆食事制限の細かな設定**: 「現金のみ⚠️」警告やキャッシュレスブランド、ヴィーガン・ハラール等の詳細設定。
   - **LocalStorage永続化**: 追加・編集した店舗はブラウザに自動保存され、リロードしても消えません。
   - **JSONエクスポート/インポート & data.jsコード出力**: データのバックアップやプロジェクトへの永続反映もワンクリック。

7. **留学生のための別府グルメ豆知識バナー**
   - 食券機（千円札と小銭のみ対応が多い問題）
   - 亀の井バス通学で使う交通系IC（Nimoca/SUGOCA）の活用
   - 和食の「出汁（魚エキス）」に関する注意

## 🚀 使い方・起動方法

### 方法1: ブラウザで直接開く（ダブルクリックでOK）
1. フォルダ内の `index.html` をダブルクリック（またはChrome/Safariにドラッグ＆ドロップ）するだけで、すぐに動作します。
2. 外部ライブラリのインストールやnpmコマンドは不要です。

### 方法2: ローカルWebサーバーで開く（推奨）
現在、ローカルサーバーがポート `8080` で稼働しています：
- ブラウザのアドレスバーに以下を入力してアクセス：
  ```
  http://localhost:8080
  ```

※もしサーバーを再起動したい場合は、ターミナルで以下を実行します：
```bash
python3 -m http.server 8080
```
